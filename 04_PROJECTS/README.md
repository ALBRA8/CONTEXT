# Proyectos ALBRA

- Estado: PROPOSED

Esta carpeta contendrá fichas de proyectos, no copias completas de sus repositorios.

Cada ficha debe responder:

- Qué es el proyecto.
- Qué problema resuelve.
- Qué agente/sistema lo ejecuta.
- Estado actual.
- Dependencias.
- Decisiones relevantes.
- Riesgos y pendientes.
- Fuente de verdad técnica.

No crear una ficha solo por existir un repositorio: primero debe existir conocimiento reutilizable que justifique documentarlo.
