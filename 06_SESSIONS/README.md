# Sesiones históricas ALBRA

- Estado: PROPOSED

Las sesiones no son fuente normativa por defecto. Solo deben conservarse cuando aporten decisiones, descubrimientos, procedencia o conocimiento reutilizable.

Reglas:

1. No volcar conversaciones completas sin necesidad.
2. Extraer decisiones, hechos, experimentos y pendientes.
3. Marcar claramente qué fue aprobado y qué quedó como propuesta.
4. Evitar datos personales, secretos y material sensible.
5. Si una sesión contradice una decisión posterior aprobada, prevalece la decisión vigente.
