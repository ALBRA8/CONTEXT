# ALBRA-CONTEXT

Memoria externa, versionada y portable para conservar el contexto de ALBRA entre modelos, cuentas, dispositivos y plataformas.

## Punto de entrada

Empieza por [`ALBRA_BOOTSTRAP.md`](./ALBRA_BOOTSTRAP.md). Describe el propósito del sistema, la jerarquía de autoridad, los estados documentales, las reglas de seguridad y el protocolo de incorporación para nuevas IA.

## Principios

- Mantener una fuente canónica por concepto.
- Diferenciar propuestas, decisiones aprobadas y hechos verificados.
- Registrar decisiones y cambios importantes con trazabilidad.
- Cargar solo los documentos necesarios para la tarea.
- No publicar credenciales, tokens, claves privadas ni datos sensibles.
- No modificar el Seed congelado de `AGENTE-GENERAL` desde este trabajo.

## Estado del repositorio

Este repositorio está en construcción progresiva. La existencia de un documento no implica que su contenido esté aprobado o que las afirmaciones citadas hayan sido verificadas de forma independiente. Consulta el estado y el historial de cada documento.

## Estructura

- `ALBRA_BOOTSTRAP.md`: entrada universal y protocolo de incorporación.
- `README.md`: presentación y navegación del repositorio.
- `SECURITY.md`: reglas para proteger información y reportar incidentes.
- `CHANGELOG.md`: registro de cambios relevantes.

Los documentos especializados se añadirán cuando exista contenido canónico que justifique su creación; no se crearán carpetas vacías solo para completar un esquema.

## Contribuciones y cambios

Propón cambios con alcance claro y justificación. No declares una decisión aprobada sin aprobación real. Para cambios importantes, registra la decisión, revisa las referencias afectadas y verifica el resultado antes de describirlo como confirmado.

## Certificación de AGENTE-GENERAL

Las referencias a commits y certificaciones de `AGENTE-GENERAL` se conservan como referencias documentales. No deben describirse como pruebas reproducidas independientemente salvo que se hayan ejecutado y registrado esas verificaciones.
