# Prompts y marcos ALBRA

- Estado: PROPOSED

Aquí se conservarán únicamente prompts y frameworks reutilizables que tengan valor transversal o sean fuentes canónicas de un proyecto.

No almacenar secretos, credenciales ni instrucciones que dependan de una sesión privada sin sanitización.

Cuando un prompt tenga versiones, registrar versión, propósito, estado, fuente y cambios principales.
