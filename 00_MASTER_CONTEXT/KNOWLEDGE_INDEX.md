## Reglas para mantener el índice

1. Añadir una entrada cuando se cree una fuente canónica relevante.
2. Evitar duplicar contenido: describir brevemente y enlazar a la fuente.
3. Marcar claramente documentos propuestos, aprobados, obsoletos o históricos.
4. No usar el índice para convertir una afirmación en evidencia.
5. Revisar enlaces cuando se renombre, sustituya o archive un documento.
