# Auditorías ALBRA

- Estado: PROPOSED

Esta carpeta conserva auditorías y verificaciones resumidas. Cada auditoría debe indicar alcance, fecha, fuente, evidencia, resultado, limitaciones y si la verificación fue reproducida o simplemente documentada.

## Regla de evidencia

No usar una auditoría para afirmar más de lo que realmente verificó. Distinguir siempre entre `DOCUMENTED`, `REPRODUCED`, `INFERRED`, `NOT_VERIFIED` y `ESTIMATED` cuando corresponda.
